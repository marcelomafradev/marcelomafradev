### IA no fluxo

Trabalho IA-first, e não no sentido de autocomplete mais rápido: o processo de engenharia foi redesenhado em volta de agentes, com o rigor que se cobra de qualquer sistema em produção.

Mudança relevante começa por spec e plano, não por código — problema, restrição, critério de aceite e tarefas com teste próprio. Planejar, implementar, depurar e revisar são trabalhos diferentes, então cada fase vai para o modelo que rende melhor nela, e quem escreve o plano não é quem implementa. Execução é sequencial e isolada: uma tarefa por vez, em branch própria.

As convenções do projeto vivem no repositório como instrução executável, versionadas junto com o código — agente novo herda a regra em vez de adivinhar. O agente lê board, banco, navegador e CI por MCP, em vez de contexto colado à mão.

Teste falhando antes da implementação; lint, typecheck, cobertura e e2e no CI como portão objetivo. Revisão humana é a porta do merge — agente acelera a produção de código e, junto, a de código errado; o ganho está nos portões, não em confiar mais.

### Testing

Stack: **Vitest**, **Testing Library**, **Playwright**.

Layout:

- Unit: `src/**/tests/unit`
- E2E: `tests/e2e`

| Command | Description |
| --- | --- |
| `pnpm test:unit` | Run unit tests (Vitest) |
| `pnpm test:coverage` | Unit tests with coverage gate |
| `pnpm test:e2e` | Playwright end-to-end tests |
| `pnpm test:all` | Coverage + e2e |

Coverage thresholds: **90%** lines / functions / branches / statements (`vitest.config.mts`).

Coverage excludes (one-line reasons):

- `src/**/*.d.ts` — type declarations only
- `src/types/**` — type-only modules
- `src/**/index.ts` — re-export barrels
- `src/tests/**` and `src/**/tests/**` — test helpers and suites
- `src/app/[locale]/**` — locale route shells covered by e2e smoke
- `src/proxy.ts` — Next.js edge proxy wiring
- `src/i18n.ts` — next-intl bootstrap
- `src/components/ui/sidebar.tsx` — third-party-style UI shell

E2E: Chromium only, `locale: pt-BR` in `playwright.config.ts`. Contact, Spotify, and Chess integrations use mocks — no live credentials required.

CI (`.github/workflows/ci.yml`): `lint` → `typecheck` → `test:coverage` → `build` → Playwright Chromium install → `test:e2e` (`CI=true`). On failure, uploads the `playwright-report` artifact (7-day retention).

Coverage matrix:

| Area | Unit | E2E |
| --- | --- | --- |
| lib / helpers / constants | yes | — |
| API routes | yes | intercepts |
| hooks | yes | via UI |
| components/ui | yes | — |
| atoms / molecules / organisms / templates | yes | smoke |
| pages (locale routes) | — | smoke + nav |
| Spotify / Chess integrations | mocked unit | mocked e2e |
| Contact form | unit + API | e2e happy path |
